A one-line roast of my own AI agent: it fact-checks itself by asking itself — and itself always agrees — so the most confidently wrong answer in the building gets peer-reviewed by a committee of one. The joke targets the self-review loop: no outside check ever gets a say.

## Run it

```bash
python3 main.py
```

It prints the roast and writes it to `/output/entry.txt`.
